# main_v1 最新前后端整合

日期：2026-10-21。仓库：`D:/kylin/rainbow_bridge`。目标：个人Fork的`main_v1`分支。

这轮把最新前后端代码收敛到同一版本。首页展示当前生效版本、配置数量、范围和真实生效时间，图片、文件、颜色与富文本提供对应预览，仍可查看和复制原文；发布详情复用这些展示能力。工作台文字与操作入口沿用现有光谱UI做了精简，没有增加新的设计系统。

旧`/api/v1/runtime/config`和`/api/v1/runtime/static`都统一读取生效快照，不再暴露未发布编辑内容；原有请求参数位置保留。旧配置JSON字段兼容，静态包统一为`config.json`、`manifest.json`和`assets/`，错误使用真实HTTP状态。首页生效时间来自后端`activated_at`，不会把页面刷新时间冒充发布生效时间。编辑区预览与鉴权保持现状。

整合时同步了冻结、发布、导入导出和首页规格的旧文字/旧接口断言。测试中显式发布后才读取runtime，静态资源通过清单与原始字节逐项核验。默认静态导出补齐了超时边界及同一快照计划复用，测试覆盖切版并删除旧版本时在途包仍完整、后续请求跟随新版。备份恢复脚本使用真实登录和CSRF，缺快照文件时新旧runtime都失败，补回文件免重启恢复。
