# Rainbow Bridge v5.0.2

为纯内网明文 HTTP 部署提供显式的非安全 Cookie 开关，便于无法使用 HTTPS 的内网场景登录管理界面。

## 新增与改进

- 新增配置项 `auth.allow_insecure_remote`：显式设为 `true` 时，允许在非回环地址监听的服务上配置 `auth.cookie_secure: false`，使浏览器在明文 HTTP 下也能保存管理会话 Cookie。
- 安全默认值不变：未配置 `cookie_secure` 时仍默认强制 Secure；`allow_insecure_localhost` 仍仅限回环监听；两个开关都未开启时，非回环 + 非 Secure 组合依然拒绝启动。会话 Cookie 明文传输可被网络监听截获，仅在可信内网启用，生产暴露面请始终使用 HTTPS。

## 升级注意

- 仅在需要明文 HTTP 管理入口时设置这两个选项；已有 HTTPS 部署无需任何变更。
