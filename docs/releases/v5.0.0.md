# Rainbow Bridge v5.0.0

包含上游 main 合入的配置管理与发布功能，以及本次正式发版打包修正。具体代码提交见 v5.0.0 标签。

## 新增与改进

- 光谱管理工作台：统一配置、资源、环境、发布、迁移和备份操作，加入管理员登录与会话。
- 可解除的范围锁版；独立、不可修改的配置与资源快照；发布切换和回退。
- 每个环境/渠道自动递增版本号；发布前差异审阅、任意两版定向比较。
- 按编辑区、生效版本或指定版本导出迁移包；配置与资源一同迁移。
- 整实例业务备份与重启恢复，成功回退副本自动保留和轮换。
- 环境/渠道逻辑删除与同名重建隔离；配置编辑采用 revision 防止覆盖他人修改。
- 运行时接口统一读取生效版本，支持指定版本、图片/文件下载和固定静态包。
- 修复 Windows 归档、资源路径、并发写入、大整数、旧接口 scope_id 固定及未知 API JSON 404 等问题。

## 升级注意

- 本版本涉及范围身份、发布和备份数据库结构升级。升级前请备份数据库、原始资源和版本快照，暂停写入后升级；不要直接用旧二进制打开升级后的数据库。
- 管理接口要求登录会话，写操作要求 CSRF/可信来源；旧的管理密钥方式已替换。首次创建管理员需在服务进程环境设置 RAINBOW_ADMIN_INITIAL_PASSWORD，已有账号不会被该变量覆盖。
- 创建版本不再手填 version，后端返回实际编号；管理写入需要范围身份；已有调用方应按包内 API 文档升级。
- 旧 runtime/config 与 runtime/static 已改读生效版本，不再读编辑区；尚未设置生效版本时明确报错。需要指定版本和 raw 内容时使用 runtime/release。
- 整实例备份 schema 为 3，支持旧 schema 1/2 候选库升级；恢复仍需要重启，并不支持热恢复。
- 当前备份功能面向 SQLite、本地资源、Redis 关闭的单实例；K8s 多副本及 MySQL/PostgreSQL 的完整功能路径未在本轮实际验收。

## 下载说明

五个平台的应用包内含嵌入前端的 app、管理员密码重置和离线恢复工具、示例配置、部署文件及 API 文档。frontend.zip / frontend.tar.gz 是保留 assets/ 目录结构的独立前端资源包。

本批构建默认服务路径 /rainbow-bridge；包内 config.yaml 是回环地址 SQLite 快速体验配置，原仓库配置另存 config.reference.yaml。正式部署需自行配置数据库、HTTPS、可信来源与存储。校验下载文件可使用 SHA256SUMS.txt。
