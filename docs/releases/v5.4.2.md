# Rainbow Bridge v5.4.2

## 统一读取运行时配置

- `GET /api/v1/runtime/config` 支持可选的 `version`。省略时读取当前生效版本，指定时读取同一环境和渠道下的固定版本。沿用 `x-environment`、`x-pipeline` 请求头和可选 `scope_id`。
- 默认保留 Insights 现有的响应字段、配置类型以及 Logo 和 favicon 地址。显式传入 `content_format=json` 可获取网页链接对象，传入 `content_format=raw` 可按字符串获取配置内容。
- 现有的 `/runtime/release` 和两个 ZIP 下载接口继续支持原有用法，Insights 和 EWork 可以直接沿用现有请求。

```http
GET /rainbow-bridge/api/v1/runtime/config?version=v1&content_format=json
x-environment: default
x-pipeline: default
```
