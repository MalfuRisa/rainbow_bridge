# Rainbow Bridge v5.0.3

修复多架构 Docker 镜像的 arm64 变体内容错误。应用代码与 v5.0.2 完全一致，x86_64 用户无需升级。

## 修复

- 修复 `Dockerfile.Remote.BIN` 中 `ARG TARGETARCH=amd64` 默认值导致 arm64 镜像变体在多平台构建时也下载 amd64 二进制的问题（镜像 manifest 声明 arm64 但 `/app/server` 实为 x86-64，在 arm64 机器上启动报 `exec format error`）。修复后 arm64 变体正确包含 arm64 二进制，已在 arm64 节点实测验证。
- v5.0.0–v5.0.2 的 arm64 镜像变体均受此影响；GitHub Release 中的分平台二进制包（tar.gz）不受影响，一直是正确的。
