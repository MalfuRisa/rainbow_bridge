# Rainbow Bridge v5.0.1

修复 v5.0.0 在 PostgreSQL 下无法启动的问题，PostgreSQL/MySQL 用户建议直接从任意旧版本升级到本版本。

## 修复

- 修复启动阶段范围迁移自检 SQL 在 PostgreSQL 下报 `column "pipeline.environment_id" must appear in the GROUP BY clause`（SQLSTATE 42803）、导致进程反复崩溃的问题（`biz/dal/db/scope_migration.go`）。原因是重复激活记录检查的 SELECT key 表达式使用了裸列名，而 GROUP BY 使用了 COALESCE 包裹的表达式，PostgreSQL 严格校验两者必须一致；MySQL 默认宽松故未暴露。v5.0.0 发布前未在 PostgreSQL 上实际验收，本版本已修复并在 PostgreSQL 18 上验证。
