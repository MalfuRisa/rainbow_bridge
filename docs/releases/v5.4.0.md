# Rainbow Bridge v5.4.0

## 网页链接配置

- 配置管理新增「网页链接」类型，支持网址、可选图标网址和排序值。目标地址支持 HTTP(S)，发布保留查询参数和片段。
- 生效版本通过 `GET /api/v1/runtime/release` 返回 `web_link` 类型。默认 `content` 为对象，指定 `content_format=raw` 时返回 JSON 字符串。导航应用可按类型选取链接。
- 现有文本、图片、对象和历史版本继续按原类型读取。已有导航可在虹桥补录为「网页链接」，发布并生效后供新版 EWork 读取。

## 渠道管理与本地启动

- 环境管理支持编辑渠道名称和排序值。更新请求省略 `sort_order` 时保留原值，显式传入 `0` 时保存为 `0`。
- Windows 本地启动器在构建前检查快照目录能否完成暂存到正式目录的重命名，并与 SQLite 数据保持在同一实例的数据目录内。
