# Rainbow Bridge v5.4.1

## Insights 兼容修复

- 恢复公开的 `GET /api/v1/runtime/config` 和 `GET /api/v1/runtime/static`。沿用原请求头、查询参数和响应格式，两条接口都读取当前生效的发布快照。现有 Insights 可以继续读取 Logo 和 favicon 并下载品牌资源 ZIP。
- `GET /api/v1/runtime/release` 和 `GET /api/v1/runtime/release/static` 继续支持版本读取和固定导出。EWork 仍可通过现行运行时接口获取已生效的网页链接。

## 渠道更新兼容修复

- `POST /api/v1/pipeline/update` 恢复 `v5.3.0` 的 JSON、表单和 Protobuf 请求行为。请求体中的 `pipeline.sort_order` 省略、传 `null` 或传 `0` 时保留原排序，非零整数照常写入。
- 新版虹桥管理台使用 `set_sort_order` 查询参数设置明确的排序值。`?set_sort_order=0` 可将排序设为 `0`。

本地验证覆盖旧客户端请求、管理台保存排序 `0`、图标保存与生效之间的区别，以及旧接口返回的 PNG 和 ZIP 内容。
