本任务不依赖新增后端功能，可在当前前端重构中作为局部改动完成。后端专业文档已经本地撰写并经复核；远程文档是否已推送，需要发布前另行确认。

### 三项展示内容与顺序

所有路径下方的 `<版本号>`、`<UUID>` 是展示占位符，不代表实际参数值。表中省略部署前缀，组件渲染时按 §4 补齐。

| 顺序 | 能力标题 | 一句话介绍 | 方法 | 展示路径 |
| --- | --- | --- | --- | --- |
| 1 | 读取生效配置 | 获取当前环境与渠道的生效配置，跟随版本切换更新。 | GET | `/api/v1/runtime/release` |
| 2 | 读取指定版本 | 按版本号获取对应配置，其他版本的生效切换不会改变读取目标。 | GET | `/api/v1/runtime/release?version=<版本号>` |
| 3 | 导出版本资源包 | 下载指定版本的配置与配套资源，打包为 ZIP 文件。 | GET | `/api/v1/runtime/release/static?version=<版本号>&expected_snapshot_id=<UUID>` |

“指定版本”指在相应环境/渠道内已创建的快照，不要求该版本当前生效。描述不使用“永久可访问”“无需登录即可管理”等超出真实契约的承诺；逻辑删除及其他限制在专业文档解释。

### 首页移除的内容

- 删除独立的 `content_format=raw` 第四行及“可选”标签。raw 是读取参数，不是一项独立业务能力；不得因此删除实际接口支持或修改调用方。
- 不列登录、锁版、编辑区 CRUD、版本删除等管理接口，它们在专业文档中保留。
- 不增加请求头、CSRF、快照 ID 来源、响应 JSON、错误码表、精度解释、旧接口兼容说明。
- 不增加测试调用按钮、参数表单、版本选择器、代码语言切换或自动请求。

## 4. 展示与交互要求

### 信息层级

优先看到“能力标题 + 一句话介绍”，接口方法和路径作为辅助证据。使用现有光谱工作台的卡片、字体、语义色与深浅主题，不给每项能力另配大面积彩色卡片，不增加全页主操作按钮。

项目为 Vue 3 SPA、Tailwind CSS 4，使用 Radix Vue 和已有 UI 组件。研发开始前按 `vue/AGENTS.md` 使用 `$refactoring-ui`，并阅读 `$engineering-quality-preserving-refactor`（`C:/Users/MalfuRisa/.codex/skills/engineering-quality-preserving-refactor/SKILL.md`）。本次采用已有组件与简单数组驱动三行展示，不引入新组件库、请求层或通用 API 展示框架。

### 路径和复制

- 继续从项目现有 getBasePath 解析部署前缀，不硬编码 `/rainbow-bridge`；默认前缀与根路径部署都正确，不能出现双前缀。
- 三项均展示完整真实路径模板，不把 `expected_snapshot_id` 从第三项实际路径中删掉，也不把参数省略号复制出去。
- 长路径允许局部换行或局部横向滚动，不挤掉标题、文档链接、复制按钮，不造成整页横向溢出；占位符作为普通文字显示，不交给 HTML 解析。
- 保留现有复制路径能力，复制完整路径模板；无需复制域名、Cookie、请求头或当前范围。按钮无障碍名称用“复制接口路径”加对应能力名。
- 复制是路径模板辅助，不宣称“一键调用”。成功提示使用“已复制接口路径”；失败使用“复制失败，请手动选择路径复制”。
- 不把模板替换为当前 active 版本，不因为缺少当前范围或尚未发布而隐藏本模块；领导查看能力不需要先选环境或登录。
- 展开/收起和复制不会调用管理接口或触发发布、导出副作用。保留键盘可操作性和现有减少动态效果支持。
